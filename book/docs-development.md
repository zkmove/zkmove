# Docs Development and Deployment

This guide describes how to develop, build, and deploy the zkMove documentation site after the migration to [mdBook](https://rust-lang.github.io/mdBook/).

## Quick Checklist

- Edit content under `docs/**`.
- Update `docs/SUMMARY.md` whenever pages are added, removed, or moved.
- Preview locally with `make docs-serve` from this directory.
- Validate the static build with `mdbook build book` from the repository root.
- Deploy through the repository-root GitHub Pages workflow.

## Prerequisites

Install mdBook once if it is not already available:

```bash
make docs-install
```

You can also install it directly with Cargo:

```bash
cargo install mdbook --locked
```

Check the installed version:

```bash
mdbook --version
```

## Local Preview

From this directory:

```bash
make docs-serve
```

Or from the repository root:

```bash
mdbook serve book --open
```

The local URL is usually:

- `http://127.0.0.1:3000`

## Build Check

From this directory:

```bash
make docs-build
```

From the repository root:

```bash
mdbook build book
```

The generated static site is written to:

- `book/book/`

This directory is generated output and should not be committed.

## GitHub Pages Deployment

Deployment is handled by the repository-root workflow:

- `../.github/workflows/docs-gh-pages.yml`

The workflow builds the docs with:

```bash
mdbook build book
```

Then it uploads this generated directory to GitHub Pages:

- `book/book/`

The workflow runs on:

- Pushes to `main` that touch docs-related files.
- Manual trigger through `workflow_dispatch`.

In GitHub repository settings, configure Pages to use **GitHub Actions** as the source:

- `Settings` → `Pages` → `Build and deployment` → `Source` → `GitHub Actions`

## Docs Structure

- `book.toml` — mdBook configuration.
- `docs/SUMMARY.md` — sidebar and chapter order.
- `docs/index.md` — home page.
- `docs/user/**` — user guide pages.
- `docs/litepaper/**` — litepaper pages.
- `theme/mdbook-custom.css` — optional custom mdBook CSS.
- `scripts/docs-build.sh` — build helper script.
- `scripts/docs-serve.sh` — local preview helper script.

## Adding or Moving Pages

1. Add or move the Markdown file under `docs/**`.
2. Add the page to `docs/SUMMARY.md`.
3. Run a local build:

   ```bash
   mdbook build book
   ```

4. Open the local preview and check navigation:

   ```bash
   mdbook serve book --open
   ```

## Troubleshooting

### `mdbook: command not found`

Install mdBook:

```bash
cargo install mdbook --locked
```

Then verify it is available on your `PATH`:

```bash
mdbook --version
```

### GitHub Pages did not update

Check the following:

- The Pages source is set to **GitHub Actions**.
- The workflow `../.github/workflows/docs-gh-pages.yml` completed successfully.
- The changed files match the workflow `paths` filters.
- The generated artifact path is `book/book/`.

### A page does not appear in the sidebar

mdBook only shows pages listed in `docs/SUMMARY.md`. Add the page there and rebuild.

## Maintenance Notes

- Keep `docs/SUMMARY.md` navigation in sync when adding or moving pages.
- Keep page titles concise for better sidebar readability.
- Prefer relative links between documentation pages.
- Do not edit files under `book/book/`; they are generated by mdBook.
